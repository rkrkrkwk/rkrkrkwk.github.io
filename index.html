2D RPG Core Mechanics (1인 개발)

Unity 2D C# ScriptableObject Event-Driven Architecture

RPG의 핵심 요소인 인벤토리, 스탯, 장비, 스킬 시스템을 구현한 프로젝트입니다. 각 시스템 간의 직접적인 참조를 줄이고, 확장성 있는 구조를 만드는 데 집중했습니다.

주요 구현 시스템

인벤토리 & 아이템

  • ScriptableObject 기반 데이터 설계
  • UI와 Logic 분리 (MVC/MVP 형태)
  • 아이템 습득, 슬롯 이동, 소모 구현

스탯 & 장비 연동

  • Base Stat 및 Bonus Stat 분리 연산
  • 장비 착용/해제 시 실시간 스탯 반영
  • 이벤트 구독을 통한 UI 자동 갱신

스킬 시스템

  • 스탯 계수 연동 데미지 연산
  • 스킬 쿨타임 및 자원 소모 로직
  • 모듈식 스킬 발사체 설계

💡 기술적 고민 및 구조 개선 (Decoupling)

문제: 초기에는 장비 착용 시 스탯 변경과 UI/스킬 데미지 갱신이 직접 참조로 얽혀있어 버그 수정 및 확장 시 어려움이 있었습니다.

해결: C# Action 기반의 Event 구독 방식을 도입하여 장비 변경 이벤트 수신 시 각 시스템(UI, 스탯 연산기)이 독립적으로 반응하도록 리팩토링하여 클래스 간 의존성을 크게 줄였습니다.
